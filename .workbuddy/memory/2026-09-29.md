# 2026-09-29

## 日历订阅：客户端支持情况核实（决定运营口径）

背景：社员反馈华为手机上"找不到订阅入口"。核实后确认是**术语错位**，不是操作问题。

**关键结论（依据华为官方支持文档，适用 HarmonyOS 5.0 ~ 7.0）**

1. 华为日历里的「订阅」= 左上角「订阅服务管理」，属华为自家内容元服务（黄历/星座/赛事），**不接受外部 ICS 链接**。社员在那儿找必然找不到。
2. 华为日历真实入口叫 **「日历 → 左上角 ☰（旧版 EMUI 为右上角 ⋮）→ 添加 → 导入日程 → URL 导入」**，官方措辞是"完成日程信息导入"——**一次性快照，不自动更新**。
3. 纯血鸿蒙（HarmonyOS NEXT / 5.0+）**不能装安卓 APK**，ICSx⁵ / DAVx⁵ 等安卓兜底方案全部失效；社区确认鸿蒙日历"暂未开放 ICS 链接实时订阅"。
4. 华为支持的长效协议是 **CalDAV**（官方文档明确有「添加 CalDAV 日历」）。本站暂未提供 CalDAV 端点 —— 若华为社员占比高，可补只读 CalDAV 子集（`OPTIONS` + `PROPFIND` + `REPORT calendar-query`，复用 `buildIcsBody()`）。

**其它客户端已核实的硬事实**
- Google 日历：**只能网页版添加** URL 订阅，官方明确移动 App 不支持；刷新约 24h。
- Outlook：移动 App 也不支持直接订阅，须先网页/桌面端添加。
- Windows 自带「邮件和日历」App 已于 **2024-12-31 停止支持**，改用新版 Outlook，别再推荐旧日历。
- 三星、小米自带日历均有原生订阅入口（三星：设置→管理日历→订阅日历；小米：右上角 ＋→订阅日历）。

**未决**：反复「URL 导入」同一链接是否造成事件重复堆积，未实测（UID 稳定，理论上应原地更新）。
